With the collet, nut, and bit installed on the spindle, position the spindle over Slot 1 of the magazine. Use the Jog controls to lower the spindle until the nut blocks the IR sensor, while keeping the nut centered inside Slot 1 as much as possible. Watch the IR indicator next to this button — it stays green while the beam is clear and turns red the moment the nut breaks it. Once it's red, click Auto Detect — the plugin will calculate Z, Zone 1, and Zone 2 for you. With an Aux port selected the lamp is read from the controller with M66, so it refreshes while the machine is idle — pause a moment after each jog step to see it update.

Events

Pre Tool Change

G-code commands executed before each tool change (M6). E.g. turn off coolant, open ATC cover.

Post Tool Change

G-code commands executed after each tool change (M6) completes. E.g. close ATC cover, restore coolant.

Pre TLS

G-code commands executed right before the tool-length probe starts, once the spindle is parked over the tool setter at the probe-start Z. Use it to switch on a wired tool setter (e.g. M64 P1), open a shroud, or dwell before probing.

Post TLS

G-code commands executed immediately after the probe retracts, before the tool length offset is applied. Use it to switch the tool setter back off (e.g. M65 P1), close a shroud, or restore dust collection.

Abort Event

G-code commands executed when a tool change is aborted. E.g. close ATC cover, turn off the spindle.
