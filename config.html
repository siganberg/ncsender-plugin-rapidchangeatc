Setting these by hand (no Auto Detect)

All three values are fixed offsets from a single reference — the release point, the height at which the collet nut stops blocking the IR beam. Auto Detect just measures it for you.

  1. Install a collet, nut and bit, and jog the spindle over Slot 1.
  2. Lower the spindle until the beam is blocked. Watch either the IR lamp above (it turns red) or the LED on the magazine's IR receiver — the physical LED is the one to trust when the aux port can't be polled reliably, since it reflects the sensor itself rather than what the controller managed to report.
  3. Now move back up slowly — fine jog steps (0.1 mm or less) — watching the LED the whole way, and stop the moment the beam clears and the LED changes back. Note the machine Z: that's the release point. Going up slowly is what makes the reading repeatable; overshoot it and you have to drop back below the beam and creep up again.

Always approach upward. The height where the beam breaks going down isn't quite where it clears going up, and Auto Detect always measures the clearing edge — approaching the same way keeps a hand-measured value consistent with it. Zone 1 sits below the release point (beam blocked, tool present) and Zone 2 above it (beam clear); the tool change checks both, so a good load reads blocked at Zone 1 and clear at Zone 2.

IR
With the collet, nut, and bit installed on the spindle, position the spindle over Slot 1 of the magazine. Use the Jog controls to lower the spindle until the nut blocks the IR sensor, while keeping the nut centered inside Slot 1 as much as possible. Watch the IR indicator next to this button — it stays green while the beam is clear and turns red the moment the nut breaks it. Once it's red, click Auto Detect — the plugin will calculate Z, Zone 1, and Zone 2 for you. If the sensor can't be read from here, open Setting these by hand below the zones — the same three values can be worked out from one jogged measurement. The lamp only follows a Probe/TLS sensor — an Aux input isn't reported live, so it shows as unlit there and the by-hand method is the way to set the values.

Sensor

Options

On (default): the tool change waits for the spindle to reach the commanded RPM before plunging. Needs a VFD that reports its speed back to the controller. Off: it does not wait, which makes tool changes quicker, and the plugin emits a G65 P6 before the M3/M4 and before the M5.

One M6 becomes dozens of generated lines. Off, the terminal shows only your M6 T3 and runs the rest silently. On, every generated line is printed as it is sent, which helps when dialling a magazine in.

Events

Pre Tool Change

G-code commands executed before each tool change (M6). E.g. turn off coolant, open ATC cover. Runs in the units the program is using (G20/G21), not always millimetres — so put an explicit G20 or G21 in the snippet if it contains coordinates. Units and distance mode are restored afterwards, so anything modal you set here cannot leak into the rest of the job.

Post Tool Change

G-code commands executed after each tool change (M6) completes. E.g. close ATC cover, restore coolant. Runs in the units the program is using (G20/G21), not always millimetres — so put an explicit G20 or G21 in the snippet if it contains coordinates. Units and distance mode are restored afterwards, so anything modal you set here cannot leak into the rest of the job.

Pre TLS

G-code commands executed right before the tool-length probe starts, once the spindle is parked over the tool setter at the probe-start Z. Use it to switch on a wired tool setter (e.g. M64 P1), open a shroud, or dwell before probing.

Post TLS

G-code commands executed immediately after the probe retracts, before the tool length offset is applied. Use it to switch the tool setter back off (e.g. M65 P1), close a shroud, or restore dust collection.

Abort Event

G-code commands executed when a tool change is aborted. E.g. close ATC cover, turn off the spindle.
